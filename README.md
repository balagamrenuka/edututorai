# 📚 EduTutor AI

EduTutor AI is a personalized learning platform powered by AI, built using Streamlit. It supports local quiz generation, student/teacher dashboards, PDF Q&A, Google login, and analytics — all without needing a database.

---

## 🚀 Features

- 🧠 AI-generated quizzes (local or using Gemini/OpenAI)
- 👨‍🏫 Role-based login (Student / Teacher)
- 📚 Google OAuth 2.0 Login + Guest Access
- 📊 Visual analytics dashboard
- 📄 PDF Q&A support using AI
- 💬 Ask AI assistant
